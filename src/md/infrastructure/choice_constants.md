# A closed set of choices is an enum

A closed set of choices is an `enum`, never a family of integer constants (`MODE_A :: 0`, `MODE_B :: 1`) passed as a `u64` or an `int`. A word that carries a choice across a border becomes its member at one place, which refuses a word that names no member. This file records the rule, the check of the tool that finds a family that breaks it, its exceptions, and the forms that were refused.

The check is in [`docs/TOOLS.md`](../../../docs/TOOLS.md), "The rules that a check holds".

## The purpose

A family of constants is checked by nobody. A `switch` on a `u64` compiles with a member missing, and its default case quietly turns a value that names nothing into a known one. Three faults of this kind were in the system:

- `principals.mode_words` turned each mode that it did not know into "an unlock", and `unlock` ran an unlock for each word that named no mode. A host test checked that silent default.
- `random.generator_from_context` read a strength of the seed past the last one as the strongest: a starter that wrote a wrong word made each key of its child look as strong as `rdseed`.
- The console showed "holds" for a state of a client key that it did not know, and read an unknown cause of a refused change as `Unknown_Change`.

An `enum` gives the compiler the set: a `switch` with a member missing does not compile, and a member cannot hold a value of no member unless a cast skips the border.

## The constraints

- The context of a process is a fixed record of 20 handles and 24 values of 64 bits, and the records of a ring, of a call and of an error have words of 64 bits. A choice travels as a word. The word cannot become an enum in the record: the record is the layout that two processes agree on.
- The values of a word are the contract of the two sides. They do not move when a member is added.
- The kernel is freestanding and has no support package. A contract package has no kernel operation.
- The tool reads the sources with the parser of the compiler library. It has no type checker: it does not know the type of a parameter of another package, nor the value of a variable.

## The chosen form

**The enum.** A closed set is an `enum`. When its word crosses a border, each member has its value written: `Unlock = 0, Create_Principal = 1`. The type is the width of the word (`enum u64` for a context value, `enum u32` for the kind of a ring record).

**The border.** One procedure reads the word: `<enum>_of_word(word) -> (member, ok)`. It walks the members and gives `ok` false for a word that names none. Each place that reads such a word calls it, refuses the word with its error record, a line of the log or a stop, and passes the member past that place. `enum_word.member_of_word` is the one generic form, in the contract package `enum_word`, so that the kernel, a contract package, a support package and a process call the same loop. It compares in 64 bits, so a word past the width of the enum (256 for an `enum u8`) is refused, where a cast would cut it to a member.

**The kernel.** Each choice of a command record (the level of `Log`, the kind of `Device_Create` and of `Inspect`, the answer of `Fault_Answer`, the action of `Fault_Handler_Set`, the strategy of `Strategy_Set`, the command of `Thread_Control`) goes through `enum_word.member_of_word` in `execute`, and again in the diagnosis that reads the same word after the refusal. One cast stays, by design, and the check of the casts names it as an exception: the dispatch on `Operation`. Its default branch is the place that refuses a kind of no operation and reads the bit of a table of error details, at no cost to a command with no table ([../features/kernel_error_details.md](../features/kernel_error_details.md)); that branch then reads the kind through `enum_word.member_of_word`. A choice of the kernel alone is an enum too: why the kernel stops the machine (`Machine_Stop_Reason`, whose values are the codes that the tool reads), the state of the measure of the serial port, and the status of an operation inside the kernel (`Operation_Outcome`: each `op.Status` with its value, and `Needs_Control`, the request of the control lock, which one border turns into the status of the completion).

**The border is a procedure that a host test calls.** The decision of each border of a process is a procedure of a package with host tests, which takes the word and gives the member or the refusal, with its error record, and reads and changes no state: `root_ring.command_of_word` for the kind of a record of the root ring (`Unsupported`, and None is refused too), `root_ring.member_of_word` for the words of the root commands (`Bad_Operation` and the record `Bad_Value` of the command and the argument), `root_ring.machine_key_report_of_values` for `Machine_Key`, `tpm_service.request_of_record` for the TPM service (`Bad_Command`), `principals.unlock_mode_of_word`, `twins.twin_mode_of_word` and `kernel_events_rounds.round_of_word` for the words of a context and of a shared page, whose refusal is a line and a stop. A process then has no decision of its own to test: it writes the refusal that the procedure gives. A module is not built for a host test, so a decision inside it would have no test of its refusals.

The borders of the library have the same form:

- `display.event_of_record` and `terminal.input_of_record` read an input record. `next_event`, `input` and `key` write one line of the log for a refused record and read the next one: a loop of input never ends on a bad record, and the budget of the log bounds the lines.
- `system.status_of_word` reads the status of a completion of the kernel. A completion of a ring of a service, the root service too, holds the word of its call outcome, which `call_outcome.completion_outcome` reads. A word that names no status is the refusal `Bad_Operation` with the record `Bad_Value` of the word. It is never the status that the caller happens to test.
- `errors.kind_of_word`, `unit_of_word` and `end_of_word` read the words of an error record. The sentence of a refused word says the number and that it names nothing.
- `block.command_of_word` and `frame.command_of_word` read the command of an error record. The names of the values are an enumerated array, `ARGUMENT_NAMES`, which the compiler checks whole.
- `system.service_command_of_record` reads a command of the service ring, `None` refused.
- `palette_table.value_kind_of_word` and `outcome_of_word` read the answer of the palette provider, `replacement_list.scope_of_word` reads the scope of a row, and `value_kinds.value_kind_of`, `terminal.code_kind_of` and `terminal.tone_of_byte` read a byte of a kind or of a tone. Each gives `(member, ok)`.
- `call_outcome.outcome_of_word` reads the call outcome word of an answer: a word that names no member gives `Answer_Unreadable` with the record of the word (src/md/api/call_outcome.md).

A refusal of a byte of style is a color, not a member. A tone that names no tone draws in the color of plain text, and a kind that names no kind gives no color of its own. A list row whose icon names no icon is not kept, its code runs go with it so that no later row takes them, and the terminal counts it.

**A comparison with the word of a member is not a cast.** `completion.kind != u32(call_outcome.Call_Outcome.Succeeded)` reads no member from the word: it compares the word with one value of the contract. It is the form where only one member matters. `system.Status(completion.kind) != .Ok` is the same comparison written with a cast: the value of the cast is compared once and never kept, passed or switched on, so it reads no member either. New code writes the first form; a value that is kept (a variable, an argument, a field, a return, an index, a `switch`) always comes from a border. A comparison with a variable is not that form: `errors.Kind(error.kind) == expected` keeps a member that the word may not name, and the code writes `error.kind == i64(expected)`. The check of the tool holds this rule (below).

**A choice by a place is not a word.** A place among the members, from 0, that the code computes (the day of the week from a count of days, the two bits of the type of a QUIC long header, the animation that a draw chose) picks its member from a table of the members in order (`weekdays_in_order[place]`), or through the border when the place can pass the last member. The tool, a host program, picks one with `enum_member_at`, which stops the tool on a place past the last member: a draw of the fuzzer is a choice of the tool, never a word of another party.

**The borders of the processes.** A process reads a word of a context, of a ring or of a shared page through `enum_word.member_of_word` at the place where it takes the word, or through a border of the contract of the enum. The kind of a command record of a ring has a border of its own in its package, which refuses `None` too, so that a host test gives it each refused word: `block`, `frame` and `datagram.command_of_ring_word`, `datagram.control_of_ring_word`, `display.control_of_ring_word`, `input_of_ring_word` and `command_of_ring_word`, `terminal.kind_of_ring_word`, and `palette_table.command_of_ring_word`. The refusal follows the place: a command of a ring gets its error record (`Unsupported`, as the block, frame and network services give), a word of a context is a line and a stop of the process (`debugged`, `return_fault`, `fault_ring`, `kernel_events`, `locker`), and a record of another process in a loop that must go on is counted, with one line at the first refusal and one line with the count when the window closes or the process stops (a window command of the compositor, a record of the terminal ring). A process only answers what its border decided, and a machine case shows that wiring: a client that the root service already starts sends `None`, the word one past the last member and the largest word of the field, and the scenario waits for each answer. `disk` sends them to the block service and on the ring of its window, `net` to the network service, and `hostile_terminal`, a test module with the grant Terminal only, to its terminal. A completion is checked field by field, with the next command served after it. A ring with no answer is checked by the count of the records that its reader read; the scenario waits for the line of the reader and its count. A process never stops the machine.

The frame service and the palette provider of the console have no such case. Their one writer is a process of the system, the network service and the compositor, and no test process can hold their ring: it would need the grant `Network_Device` or the place of the compositor, which the root service gives to no test process. A test module with such a grant would be a new authority for a test, so the two borders keep their host tests only. Where the process writes the word itself, it keeps the member and passes it with the word: the compositor gives `window_event_send` the kind of the event it sends, and reads no word back.

**A word in place of an enum field.** A field of a record that two parties share and that holds a choice has the type of its word (`u8`, `u32`, `u64`), not the enum: `terminal.Style.tone` and `.code`, `terminal.Code_Run.kind`, `value_kinds.Value_Run.kind` and `Value_Run_In_Call.kind`, `palette_table.Entry.kind`, `.result` and `.parameters`, `replacement_list.Row.scope`, `operation.Module_Record.writer`, `operation.Fault_Record.kind` and `Event_Record.kind`, `module.Function.result` and `.parameters`, `module.Field.type` and `module.Described.type`, `lockers.Slot.mode`, `store.Entry.kind`, `boot_info.Boot_Info.self_test`, and `Boot_Trust.key_floor_state` and `.version_floor_state`. The writer writes `u8(Tone.Number)`; the reader takes the field through its border (`tone_of_byte`, `code_kind_of`, `value_run_in_text`, `value_runs_check`, `entry_kind_of_word`, `result_kind_of`, `parameter_kind_of`, `scope_of_word`, `module_writer_of_word`, `fault_kind_of_word`, `event_kind_of_word`, `module.type_of_word` with `function_result_type`, `function_parameter_type` and `field_type`, `enum_word.member_of_word` for the mode of a locker, `store.entry_kind_of_word`, `self_test_of_word`, `floor_state_of_word`). The compiler then refuses a reader that skips the border: a word cannot be switched on as a member. A check of the whole record (`snapshot_take`, `rows`, `isolated.record_size`, the check of a module file) still refuses the record, and the reader after it reads the field through the border again, at the cost of one short loop, and gives the text or the status of "no member" for a word that the check would have refused.

The format of each of these records keeps its size, its offsets and its bytes: the word has the width of the enum that it replaces, and each `#assert` of a size stays. A comparison of a field with one member is a comparison of the word with the word of the member (`field.type == u8(module.Type.Integer)`).

The writer of a kernel record writes the word of the member that it holds (`kind = u64(fault_kind)`). The boot program keeps each floor state as its member, and writes its word in the trust record. A reader of a word that the kernel gives in a result (`system.process_state`, `handle_state`, `strategy_set`) takes it through the border, and a word that names no member stops the process with a line: the kernel and the library come from one build, and no member stands in for the word.

**The settings.** The values of the settings page and of the kept record are words. `settings.choice_of_values` reads them as one `Choice` with a member for each setting, and refuses a word that names no value of its setting. `read` then refuses the whole page, as it refuses a page that never stays stable: it gives `ok` false and the defaults with the count that it saw. A reader that draws (the compositor, the display of a process, the input service) draws with the defaults; a reader that acts on the page (the root service, the process `date`) acts on nothing. `kept_read` refuses the whole record, as it refuses a record of another version, and the boot pass writes the defaults in its place. A value is never read as the value 0 of its setting: that was a default member, which the readers then cast. `write` takes a `Choice`, so the page holds a word of a member only.

The word of a member in a table of a row is an enumerated array (`MODULE_WRITER_NAMES`): the compiler checks that it names each member, and no reader has a text such as "unknown" to give, because no reader holds a member that names nothing.

**The switch.** Each `switch` on the member names each member. No `#partial` on a closed set, and no default case. A `#partial switch` stays only on an open choice, with a comment that says why: a diagnosis of the kernel names the few operations of its status out of the whole set, and a sentence of the console names the few error kinds of one command and gives the general sentence for each other kind. Inside a case that holds a few members already, a `switch` with no value (`case command == .Read_Registers:`) picks among them, and the outer `switch` stays whole. A `switch` that must end with a `return` for the compiler gives a text or a status that says that no member was named; it never gives a member. The members that need no work share one case, with a comment that says why. When a new member comes, the compiler then stops at each switch, and the author chooses its case.

A field of a record that has an enum type can still hold a byte of no member, because the record came from a file or from another process. A whole switch takes no case for it. A test against the largest member (`type > max(module.Type)`) is no border: it lets a byte between two members pass when the values have a hole. Such a field becomes a word, and its reader takes it through its border; the records that still have an enum field are planned work.

**The check** (`choice_constant_check`, `tools/modustool/checks/choice_constant_check.odin`). It parses each source of the kernel, the boot program, the processes, the modules, the source library and the tool that is not a test, except the copy of the cryptography of Odin. For each package (one folder) it keeps the constants whose value is from -255 to 255: an integer or a character literal, a negation of one, a conversion of one, or a value of the arithmetic and of the bits on them and on other constants of the package, in a declaration of one name or of several. The negative side holds the answers of an export (`ERROR_NAME :: -3`), which are a closed set too. It then notes each such constant that the code uses as a choice:

- a value of a `case` of a `switch`, except a `switch` on `len(...)`, whose cases are quantities;
- an operand of `==` or `!=` whose other operand is a variable with a word of a choice in its name: two constants compared (`#assert(BOX_COLUMNS == FORM_COLUMNS_MOST)`) are quantities;
- a value assigned or declared to such a name, a field of a literal with such a name, or the index of an index with such a name (`values[VALUE_MODE] = MODE_A`);
- an argument of a parameter with such a name, of a procedure of the package or of an imported package.

A word of a choice is one of `mode`, `kind`, `state`, `form`, `level`, `stage`, `strength`, `role`, `phase`, `action`, `origin`, `change`, `step`, `round`, `variety`, `reason`, `request`, `choice`, `strategy`, `answer`, whole, between two `_`. The constants that the code uses as choices, of one package and with the same first word, are a family. A constant whose first word gives no family joins the constants with its last word (`READ_REQUEST`, `WRITE_REQUEST`). It joins them only then: two families of an outside standard share last words (`GUEST_EXIT_INTERRUPT`, `EVENT_TYPE_EXTERNAL_INTERRUPT`), and a third family of their members would be no set of choices. A family of two members or more is refused, with its members and its first use.

**The exceptions** are a short list in the source of the check, each with its reason. Each one is an open set of an outside standard: the frame types and the transport parameters of QUIC, the protocol numbers of IPv4, the message types of ICMP, the capability types of virtio, the entry types of IVRS, the structure and scope types of DMAR, the entry types of the table APIC, the scan codes of the keyboard, the identity bytes of a PS/2 mouse, the exit codes and the event types of AMD SVM, and in the tool the codes of DWARF and of ELF and the messages of the network block device protocol. A value that names no constant is legal there: the reader skips it, or answers it as the standard says. One row names places, not choices: the places of the fields of a remote request, which the argument of an error record names and which a test of the peer selects in a `switch`. An exception that matches no family is refused too, so the list stays true.

**The casts.** The same check refuses a cast of a word to an enum, `Mode(word)`, `cast(Mode)word` or `transmute(Mode)word`, that the code keeps, passes to a procedure or switches on, with its file, its line, the enum and the form. It accepts a cast only as one operand of `==` or `!=` whose other operand is a member: `.First`, `Mode.First` or `other.Mode.First`. It knows the enum types of each package from their declarations, those of a `when` block of the file included, a `distinct` type of an enum, and an alias of one (`Entry_Kind :: store_contract.Entry_Kind`, through an import too, read after each enum is known, as a chain of aliases is). The imports of each file name the package of a selector; a relative import (`"../x"`) names its folder with no `.` and no `..`. A cast to a pointer, a multi-pointer, an array, a slice or a dynamic array of an enum (`(^Mode)(&word)^`, `transmute([4]Mode)bytes`) makes members of words as a cast to the enum does, and is refused the same way. The walk of the syntax tree visits a node before its children: a comparison, a call and a switch mark their operands before the walk reaches the cast. The sources are parsed once for the two parts of the check.

**`auto_cast`.** The target of an `auto_cast` is the type that the compiler infers from the place: the syntax tree does not hold it, and the tool has no type checker. So the check cannot tell an `auto_cast` to an enum from another one, and it refuses each `auto_cast` in the sources that it reads: a conversion names its type. Telling them apart needs the types of the compiler, which is planned work in [`ROADMAP.md`](../../../ROADMAP.md).

The casts of a design are a second short list, each with its reason: the dispatch of the kernel on `Operation`, and the machine test of an unknown operation in `errors` that writes a word of no member on purpose. A row names its file, its enum and the count of its casts in that file: one more cast of that enum in the file, or one less, refuses the row and its casts, so a row never holds a later place that no review saw. A row that matches no cast is refused too.

**The stop words.** The stop cause and the stop outcome of a process have their borders in the contract package `operation` and in the library ([../api/process_stop.md](../api/process_stop.md)). The same parse refuses a conversion of a word to `Stop_Cause` or `Stop_Outcome` outside `operation`, in a comparison with a member too: the two enums have their borders, so no reader needs the comparison form. Outside the support package `system`, the contract package `operation`, the kernel and the tool, it refuses each mention of the operations `Process_Stop` and `Process_State`, and each conversion of a word to `Operation`. A check of the arguments of `system.call` alone was refused: a variable, a converted word or the kind of a command record that `system.commands_call` sends carries the operation past it. It refuses `system.stop(.None)` too. An alias of one of the three enums, a chain of aliases, a `distinct` type and a `#type` of one are the enum for the check: the parse collects the constant declarations whose value names one, in a file or inside a procedure, before the walk. The operation sequence runner names no operation in its source, so it needs no exception. Two tests that give the kernel a word that it must refuse are a short list of exceptions with their counts, as the casts of a design are.

**What it does not see:** a constant inside a procedure or a `when` block, an enum declared inside a procedure, a value past 255 on either side of 0, a value computed from a constant of another package, and a family whose names share neither their first nor their last word. It has no type checker: an enum of the package with the name of a procedure of an import is told apart by the import, and a cast of a member of one enum to another enum (`B(u8(a))`) is a cast of a word, which a whole switch from one to the other replaces.

## What stays a constant

A constant stays a constant when it is a quantity or a place: a size, a capacity, a limit, an address, an index in a fixed array. `GRANT_*` and `CONTEXT_*` are places in the context; `VALUE_MODE` is the place of the word of a mode, not a mode. A flag of one bit (`REMOTE_CLIENT_KEY_CAN_COME_BACK`) is not a set of choices. A mask, a magic number and a code of a standard past 255 are not read by the check.

## The refused forms

- **A check of every family of constants with one prefix.** Most families are places and sizes (`OFFSET_*`, `SCROLL_BAR_*`). The use as a choice is what makes a set of choices.
- **The enum in the record.** A record is the layout of a border. A field of an enum type would let the reader skip the border and take a word that names no member.
- **A cast at the border** (`Enum(word)`). It accepts each word. The refusal then depends on each `switch` that comes after it.
- **A clamp to the last member** (`min(word, max(Enum))`). It turns a word of no member into a member: the strength of the seed was read as the strongest.
- **A default member for an unknown word.** It is the fault that the rule removes.
- **A check of the types of the parameters.** It needs a type checker in the tool. The names of the parameters and of the fields say a choice in this system; review holds the rest.
- **A list of the families not converted yet.** Each family that the check finds is converted in the change that adds it, or is an exception with its reason.

## The subtle points

- **The values do not move.** A member added at the end keeps the words of the others. A host test of the border gives each word past the last member, the largest word, and 0 where 0 is no member, before it reads each member back.
- **`None` as a member.** `store.Entry_Kind.None`, `tpm_service.Command.None` and `Device_Step.None` are members, but no reader takes them for an entry, a command or a failed step: the border or the `switch` after it refuses them.
- **A cast that skips the border** still compiles; the check of the tool refuses it, but an enum declared inside a procedure is outside its sight, and review holds that. A `switch` that the compiler checks whole then gives the text or the status of no member, never a member.
- **A switch that must end with a return.** A mapping from one enum to another assigns a named result in each case and returns it once; it never ends with `return .None` after the switch, which would be a default member.
- **The kernel.** Its operation contract keeps its numbers: a word that a test or another language reads is put behind an enum with the same values, not renumbered.

## What is built and what is left

Built: the check and its host tests; the families of the modes of `unlock` and of a twin, the words of the root ring (`Remote_Client_Action`, `Remote_Client_State`, `Principal_Change`, `Disk_Grant_Action`, `Machine_Key_State`, `Machine_Key_Form`, `Principal_Key_Origin`), the ends and the causes of a change of a passphrase, the strength of the seed, the authorization, the step, the command and the status of the TPM service, the kinds of a session of the TPM, the kinds of a storage entry, what did not answer in a `No_Answer` record, the rounds of `kernel_events`, and the accents of the dead keys; the borders of the root commands, of the TPM service, of a context and of a shared page as procedures with host tests; the casts of the status of a replacement in the console and of the kind of a new entry in the storage service; the border of the writer of a module record (`operation.module_writer_of_word`) and the whole switches of the rights of `Thread_Control`; the borders of the words of the kernel operations, the action of `Fault_Handler_Set` and the layout of the extended state area that `Thread_State` gives as enums of the contract, the reasons of a stop of the machine, and the whole switches on `Object_Kind` in the kernel.

The check also reads the negative constants. The failures of an export are members of `call_outcome.Call_Outcome`. The borders of the library each have a host test, and each closed set of the support library and of the contract packages has a whole switch, except the network packages and the root ring.

Built too: the words of the processes, of the boot program and of the kernel read at their border (the commands of the block, frame, network, compositor, console and terminal rings, the modes and the roles of a context, the statuses that a process keeps, the kind of a guest exit, the pixel format of the firmware, the vector of a fault, the self test of the build, which the build refuses past the last test); each `switch` on a closed set there and in `src/library/modus/contract/operation` whole, the open choices of the kernel diagnosis and of one sentence of the console with their comment; and the word in place of the enum of the tone and the code kind of `terminal.Style`, of the kind of a value run, of the kind of an entry of the palette table, of the scope of a replacement row and of the writer of a module record, each with its readers through the border.

Built too: the word in place of the enum of the kind of a code run of the terminal, of the result and the parameter kinds of an entry of the palette table, of the types of a module file (the result, the parameters and the type of a field, and the side of a difference of a load error), of the kind of an event record and of a fault record of the kernel, of the mode of the lockers board, of the kind of a storage entry, and of the self test and the floor states of the boot information, each with its readers through the border and a host test of the border; the settings read as members, with a page or a kept record refused whole for a value that a setting does not have; and the check of the casts, with each cast of `src/` and of the tool that it refused replaced by a border, a comparison of words, a table of the members in order, or a whole switch from one enum to another.
Built too: the machine cases of the refused words of the block service, the network service, the ring of a window and the terminal ring.

Built too: the remaining shared-record enum fields converted to unsigned words with strict `enum_word.member_of_word` borders and adversarial host tests: `operation.Event_Rule.kind` (`event_kind_of_word`, `event_rule_check_fields`), `date.Page.source` (`source_of_word`), `remote.Request.kind` (`request_kind_of_word`, removing the `peer_remote.odin` cast exception), `module.Function.parameter_directions` and `module.Described.direction` (`direction_of_word`, `function_parameter_direction`), `module.Load_Error.{stage,file_error,difference}` (`load_stage_of_word`, `file_error_of_word`, `difference_of_word`, with `Error_Word` and `Difference_Word` in `Load_Read_Fields` and `Load_Check_Fields`), and `boot_info` (`Memory_Range.kind`, `Framebuffer.format`, `Boot_Trust.{verifier,key_kind,measure}` with `memory_kind_of_word`, `pixel_format_of_word`, `verifier_of_word`, `signing_key_kind_of_word`, `measure_state_of_word`). No shared-record enum field remains in that list.

The partial switches that stay in the tool read the closed sets of the syntax tree of Odin, of which a check reads a few nodes and skips the others, and the outcome of a transport in `call.odin`. The switches of `call.odin` on `module.Type` are whole. Two partial switches stay in the contract packages, each with its comment: the command of `datagram.argument_name`, an open choice of the commands whose values have names.

**The self test of the build.** The boot program asserts the word of the build against the largest member of `Self_Test`, not each member: the values have no hole from 0 to the largest one, and a host test of `boot_info` checks that each word of that range names a test. A hole would fail that test first, and the assert would then have to name each member. The kernel reads the word through `self_test_of_word` all the same.
