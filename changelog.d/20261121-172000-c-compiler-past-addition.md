**The C of the C compiler past addition.** The assembler now encodes 8- and 16-bit registers and moves (with REX handling for `%spl`/`%bpl`/`%sil`/`%dil` versus `%ah`/`%ch`/`%dh`/`%bh`), scaled indexed SIB addressing, bitwise and shift instructions (`and`, `or`, `xor`, `not`, `shl`/`sal`, `shr`, `sar`), `test`, `imul`, `idiv`, `div`, `neg`, `inc`, `dec`, all 16 `setcc` conditions, sign- and zero-extending moves (`movsbl`/`movzbl`/`movswl`/`movzwl`/`movslq`/`movzb`/`movzx` and kin), zero-operand sign extensions (`cbw`, `cwtl`, `cltq`, `cwd`, `cdq`, `cqo`), `rep stosb`, and indirect `call`/`jmp`. C functions compiled by `c_compiler` with loops, comparisons, recursion, multiplication, division, bitwise operations, local initializers, and byte/short arrays now assemble into valid modules and run on modus.
