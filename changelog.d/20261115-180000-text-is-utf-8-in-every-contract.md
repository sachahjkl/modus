**Text is UTF-8 in every contract**: the palette table (version 6), the result runs, the candidates, the typed values of the palette, the records of the terminal and the names of the objects of a store hold UTF-8 in place of the bytes 32 to 126, checked at each border by one rule that refuses an overlong form, a surrogate, a code point above U+10FFFF, a broken sequence and a control character. A writer cuts a text after a whole character, the cells of the terminal hold one character each, and a character that the font lacks draws one replacement glyph, a box, never a byte. The names that are identifiers of the system (modules, exports, fields, settings, programs, channels of the log, and the name, act name, setting row and value of a palette entry) stay ASCII. A name of an object of a store with a control character or bytes that are not UTF-8 is now refused.
