**A module from a source outside the repository**: `kerneltool module-build <folder>` builds a module whose source is in a folder of another project, with the steps of a module of the system. The folder holds one Odin package and a file `module.txt` with the name of the module, its imports, its settings of the compiler and whether it is a library module, one `key: value` on each line. The tool finds the system with `--system` or with the environment variable `MODUS_SYSTEM`, writes `<name>.module` and `<name>.debug` in the folder `build` of the module, and prints the hash of the module and the names of its exports. A source of such a module is in its folder, in the source library `modus` or in the libraries of the compiler: the tool refuses each other place. The tool does not yet put such a module in the boot image of a machine.
