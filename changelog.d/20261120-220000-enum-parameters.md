**Enum parameters: one description for the completion, the check and the palette**: an export takes a value of a closed set as an enum, and its module file (version 6) names the members and the getter of the value in use. The console completes the members, `.french`, refuses a wrong one at its place before the call, and the palette shows one row of buttons for each such parameter, with the member in use marked. `settings.set` takes one optional argument for each setting, `settings.set(keyboard_layout = .french)`, each setting has its getter, `settings.font()`, and the time zone has `settings.set_time_zone` and `settings.time_zone`. The command `setting`, `settings.get` and the setting entries of the palette are gone; the rows of the settings appear after `connect("settings")`.
