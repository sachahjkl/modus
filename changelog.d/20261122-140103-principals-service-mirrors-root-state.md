**The principals service holds a mirror of the principals**: the root service starts `principals` before the start policy, within three starts, and keeps it told of each named principal, each lock and unlock, the machine passphrase, the whole set of rows of each disk grant table and each allow or revocation of a client key, with no wait in its loop. A `principals` that stops is started again and gets the whole state again; a refusal is one line and changes no grant.
