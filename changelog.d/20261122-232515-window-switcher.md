**Alt+Tab switches windows.** Alt+Tab opens a card of the windows, the one used last first, and chooses the window used before the one in front; each Tab chooses the next, Alt+Shift+Tab goes backward, the release of Alt brings the chosen window to the front, and Escape closes the card. The input service now gives the left Alt as the modifier bit `MODIFIER_ALT` of each key; the right Alt key stays AltGr.
