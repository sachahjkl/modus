**A browser machine takes keys.** A process with ports runs `in` and `out` on the software processor, checked against the port map of its processor, and the PS/2 controller of the page raises line 1 for the keyboard and line 12 for the mouse. So the input service runs, and `modustool browser-machine boot` types `help()` on the PS/2 keyboard once the machine is usable and requires the answer of the console in Node.
