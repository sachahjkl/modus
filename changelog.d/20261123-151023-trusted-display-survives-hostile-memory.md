type: Security

**A caller can no longer stop the trusted display with a memory object that it gives.** The display refuses an Uncommitted object of a plan difference at its border, and reads a difference and the entries of the palette by a copy of the kernel, never through a mapping: a page with no frame, or a revocation by the giver during the read, ends the dialog with no decision, or leaves the palette without the entries of its provider, and the desktop keeps running. The display makes each window surface itself, with a budget that the window gives for that surface alone, and gives the window a copy with Read and Write: `Surface_Create`, `Surface_Resize` and `Surface_Rescale` carry that budget and the size, the answer names the surface, and `display.open` waits for it; an open that fails leaves no window, and the next one makes it. The memory of the capture face comes the same way, with the new event `Capture_Opened`; the role contract of the display is version 3. So the display maps no memory that a window made, and no window can take back a mapping of the display. A paste into the palette reads the copied text by the kernel too. The palette table keeps its header, its result and its candidates in the table that the root service made; the entries that pass it move to an object of the entries alone (`Table_Replaced`, table version 10).
