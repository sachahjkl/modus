**The assistant: an agent from the desktop**: the window `assistant` takes a request of the principal and shows the reply of an agent, each act that it proposes and its result. The agent runner `modustool assistant` on the host reads the request through `remote`, asks a language model whose endpoint and key stay on the host, refuses a malformed model reply whole with its error record, and runs each act only through the host agent bridge. The endpoint is this machine unless `--key-in-clear-off-host` accepts that the key crosses the network in clear; an answer of the model has 120 seconds; the model reads the last 16 requests, and the outcome of an act speaks as a tool, never as the principal. An act that the trusted display cannot show takes a final state and holds back no later act.
