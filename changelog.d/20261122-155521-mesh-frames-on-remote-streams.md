**Machines talk over the streams of remote**: `remote` now answers the frames of paired machines on its QUIC streams, beside the calls of the host, chosen by the first word of each stream. A machine pairs by a one-use code (a wrong code ends the pairing on both machines), fetches an object by its BLAKE3 hash and keeps it only when its bytes hash to it, presents a signed grant of another principal (one day at most, or a revocation list), exchanges a store with a three-way merge that keeps both writes of an object as a conflict value until the principal resolves it once, calls a role held on the other machine (a broken link gives Unknown_Outcome, never a false refusal), and deposits sealed datagrams on a relay machine that sees only a routing token and the sealed bytes.
