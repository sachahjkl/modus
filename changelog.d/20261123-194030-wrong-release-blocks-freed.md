**The blocks that a wrong release keeps are freed on a disk larger than the memory.** A release that meets a wrong release list or a wrong node of a released state now starts a recount of the count tree: when no call waits, runs of up to 128 leaves count the names again and free each block that only the wrong release named, a leaf with no block in use is passed, and the service takes changes between two runs. A loss of power keeps the leaves still to recount, and the next start goes on from them.
