**A change of the passphrase of a named principal.** In a console of the session of a named principal, `passphrase_change()` opens the window of `unlock`, which asks for the current passphrase (the TPM counts a wrong one) and then for a new one two times; `recovery_key_change()` asks for the current passphrase and shows a new recovery key one time, and writes the file only after Enter. The window and the line of the console both give the end of the change: what changed, or why nothing changed. The keys stay the same keys, and the store keeps the file from before as a version on the same disk, so the old passphrase and the old recovery key still open that version until old versions can be erased. The console of the machine cannot ask, and a lock during a change stops it.
