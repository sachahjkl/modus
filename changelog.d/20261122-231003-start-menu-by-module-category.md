**The start menu lists what a principal uses.** Its lines come in sections by the module category: the applications, then the tools, then the demonstrations, closed until the quick action "demonstrations" opens them; a test module, a service and a library have no line, nor a module that only another process starts, or that opens no window and writes its result on the log only. Each section is in the order of the alphabet, and a line reads "hall of fame" for `hall_of_fame`.
