**The compositor and the windows write log facts**: a surface made, a window shown, in front or closed, the events that a window lost, a refused word of a ring and the element lines of each window and of the palette are records of fields, whose sentences are those of before. In the console, `log.records(0) |> facts(compositor.Window_In_Front) |> where(window = "console")` gives each time that the console came to the front, and a machine test presses an element from the fields of its last element line. The module file of a process lists only the fact types that its code writes.
