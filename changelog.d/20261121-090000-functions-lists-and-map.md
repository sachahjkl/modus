**Functions, lists and `map` in the console**: a line writes a function, `(x) => x * 2`, names it with `let` and calls it, `let double = (x) => x * 2 in double(21)`; writes a list, `[1, 2, 3]`; and calls a function on each item, `map([1, 2, 3], (x) => x * 2)` gives `[2, 4, 6]`. A function reads the bindings of its line where it is written, and its body runs only in a call. A wrong count of arguments, a call of a value that is no function, a parameter named twice, and a function or a list given to a command or kept by a variable are refused with their place. A line that nests deeper than 512 KiB of stack of the evaluator, as a recursion, stops with an error: the console runs its lines on a thread of 640 KiB of stack, where the deepest lines of 200 bytes took more than its 64 KiB before.
