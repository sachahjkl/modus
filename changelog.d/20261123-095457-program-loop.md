**A program written, built and run inside the system**: `projects.new("hello")` makes a project, `edit("hello", "hello.c")` takes its C source, `build("hello", "hello.c")` compiles it with the native C builder of `recipes` into a module in the store `module_files`, and `run("hello")` calls its export `main` in a call host with no grant. The same source again is substituted with no compile, a C error names its byte and builds nothing, and a grant that the project does not declare is refused.
