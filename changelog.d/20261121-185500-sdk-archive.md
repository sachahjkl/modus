**SDK packager, verifier, and language-neutral module converter**: `modustool sdk-pack`, `modustool sdk-verify`, and `modustool sdk-convert` assemble and cryptographically verify a self-contained SDK directory with BLAKE3 per-file and root digests plus Ed25519 signatures, and build outside modules in Odin or any compiled language emitting freestanding `ET_REL` objects with no repository checkout and no access to `internal:` or `modulus:`.
