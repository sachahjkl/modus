**Shared host module build cache, `--no-shots` test mode, and per-volume `--fast` module filtering.** Developers can opt into `MODUS_BUILD_CACHE=<dir>` or `--cache <dir>` to reuse verified module artifacts across worktrees and branch switches, pass `--no-shots` to `modustool test` to skip QMP screenshot captures during iteration runs, and compile only the modules and boot image needed by a single named volume under `modustool build --fast <volume>` or `modustool test --fast <part>`. Default builds, `check`, `repeat`, `screenshots`, `release`, and `ship` keep full optimization, full module builds, clean reproducibility checks, and full screenshot verification.
