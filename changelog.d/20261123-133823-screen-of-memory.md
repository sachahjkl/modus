**A screen of memory for a machine with no screen.** A machine with no display device, such as a server, runs the desktop and the console in memory, at 1920 × 1080 by default, and a viewer of `remote_display` sees it and drives it. A viewer with the input can ask another size up to 7680 × 4320: the desktop takes it and the windows fit it again, or the viewer gets the cause of the refusal. The remote display protocol is now version 3, and the start list is now format version 4, with the size of the screen of memory on its row `display`.
