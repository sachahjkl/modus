**A screen of memory for a machine with no screen.** A machine with no display device, such as a server, runs the desktop and the console in memory, at 1920 × 1080 by default, and a viewer of `remote_display` sees it and drives it. A viewer with the input can ask another size, at most once each second: the desktop takes it and the windows fit it again, or the viewer gets the cause of the refusal and keeps its session. The size grows up to the largest of 2560 × 1440, 3840 × 2160, 5120 × 2880 and 7680 × 4320 that the share of a process pays, which the root service pays at the start of the compositor and of `remote_display`; a larger size is refused with its cause. The remote display protocol is now version 3, and the start list is now format version 4, with the size of the screen of memory on its row `display`.
