**A screen of memory for a machine with no screen.** A machine with no display device, such as a server, runs the desktop and the console in memory, at 1920 × 1080 by default, and a viewer of `remote_display` sees it and drives it. A viewer with the input can ask another size, at most once each second: the desktop takes it and the windows fit it again, or the viewer gets the cause of the refusal and keeps its session. The budgets pay the screen at the size of its start, so a smaller size passes and a larger one is refused with its budget cause. The remote display protocol is now version 3, and the start list is now format version 4, with the size of the screen of memory on its row `display`.
