**A module category and tags in each module file.** The header of a module file says what the module is to a reader (an application, a system tool, a developer tool, a service, a library, a demonstration or a test) and up to twelve words of what it is about. The build refuses a category that the folder of the source does not allow, and a reader refuses a word that names nothing. A fifth module group, `applications`, waits for its first program.
