**A C compiler and a thin libc.** The module `c_compiler` is `chibicc`, ported: `compile(source, output)` writes a text of assembly that the module `assemble` takes, with an `export` for each function that is not `static`, over a thin libc with no path and no standard stream. In the console, `int add(int a, int b) { return a + b; }` is compiled, assembled, isolated, and `add(2, 3)` gives 5. The assembler takes `movsxd`; the rest of what `chibicc` emits past `+` and `-` is refused with its line and its column.
