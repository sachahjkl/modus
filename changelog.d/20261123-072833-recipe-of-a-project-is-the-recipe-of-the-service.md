type: Changed

**The recipe of an evaluated project is the recipe that `recipes` builds.** The new export recipes.register_evaluation takes the output of an evaluation whose value is a recipe, such as outputs.default of a project, and registers it under the hash that the evaluator wrote: the evaluator and the service compute it with one conversion. here() now gives a tree reference and module(...) a module file, each an input that names its kind, and declaration(here()) reads the declaration of the source tree. A bare hash in the arguments of a recipe, a builder, a project source or a console module given by a bare hash, an input below the first level, a source_date that is not an integer of 0 or more, and arguments whose record names are not sorted or appear twice are refused; the evaluator gives the failure Recipe_Refused with the words of the refusal.
