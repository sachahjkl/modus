**The measures of the standard of quality.** The compositor writes at its start the quality profile that it chose, the processor profile with the reason "the system drives no GPU device", and measures with the clock of the system the three numbers of the standard: the time of a frame from the first record that it reads to the page flip, the time of a key from the input service to the flip of the frame that shows its character in the console, and the start of each window from `Program_Start` to its first frame. The console names each key that it puts in its line, its terminal names it with the picture, and the compositor ties the two, so a frame that only came after a key is never counted as its effect. The measure run waits for each line, the tool checks their form only, and the measure record and its history keep them.
