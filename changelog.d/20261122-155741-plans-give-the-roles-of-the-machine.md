**Plans give the roles of the machine.** When a principal accepts a plan of principal 0 on the trusted display, `plans` gives the root service the whole set of its role holders with the root ring command `Plan_Roles` before it commits, and the root service takes the set whole or refuses it whole; `plans.rollback()` gives back the holders of the generation that it selects. `plans`, `recipes` and `projects` now start with their own private store, and `plans` with Connect to the trusted display and the start grant `Plans`.
