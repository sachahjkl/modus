**A stop report of a disk program names its procedures and its lines.** The root service keeps the stop report of a disk program that stopped on a fault, with only the frames that a module record holds, 8 reports at most, and writes `root: kept the stop report of <nickname>, a disk program of principal 0: stop_report("<nickname>") names its frames`. `stop_report("<nickname>")` in the console calls the new export `stop_report` of the debugger service, with no attach: the service receives the report with the connection that reads only to the store `programs` (the command `Debug_Store`, with the flag values[6]), reads the debug object of the module, and gives one row for each frame with the procedure, the file and the line: `outsider_fault  visitor::fault_three  outsider/main.odin   169`. The caller must act for the principal of the program. The error unit `Stop_Reports` names a nickname with no kept report.
