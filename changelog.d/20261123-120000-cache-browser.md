**The cache browser in `modustool cache-serve`, recipe objects, and signed release pointers.** The status listener of `cache-serve` now serves read-only HTML pages in the style of the site for trees (`/tree/<hash>`, paged by 100 entries), blobs (`/blob/<hash>` with module metadata, text, PNG, or hexadecimal preview, and sandboxed raw download at `/blob/<hash>/raw`), realisations (`/realisation/<recipe hash>` with signature checks and recipe inputs when the recipe object is held), release pointers (`/releases`), and bounded prefix search (`/search?h=<prefix>`), checking every read object against its hash before showing any byte. The cache wire protocol adds `Put_Release_Pointer` and `Get_Release_Pointer`, `plans_recipes` adds canonical recipe object encoding, and `cache-put release` publishes the recipe object, the release trees, and a signed release pointer.
