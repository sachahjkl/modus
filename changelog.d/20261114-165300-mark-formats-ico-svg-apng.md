**Three more formats of a file of the mark**: `kerneltool mark still --format ico` writes an icon file with one PNG entry for each size, `--format svg` writes the cells variant as rectangles, with the rule of the dark scheme on request, and `kerneltool mark animation --animation <name>` writes one animation as an animated PNG file, each frame for its time. The smooth variant as a vector file is refused with a sentence.
