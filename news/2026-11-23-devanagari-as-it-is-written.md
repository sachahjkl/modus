A process with the script font set draws Devanagari: नमस्ते and हिन्दी draw with their half forms, their conjuncts, the reph over its consonant and the vowel sign ि before its consonant.

The font is Noto Sans Devanagari, the seventh font of the script font set, which is now 36 433 492 bytes.

An engine of the lookups of OpenType, written for the system, applies the features of the font to each syllable. HarfBuzz, on the same font file, gives the same glyphs, advances and offsets for each of 34 test words.

A line never breaks inside a syllable.
