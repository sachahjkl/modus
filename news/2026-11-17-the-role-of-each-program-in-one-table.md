modus is an operating system in which a program reaches only what its starter gave it. The root service starts each program of the system with the grants of its role.

The role of each program is now one row of one table: its grants, the services that it can connect to, the size of its private store and of its terminal, and the reason of each. The page of the grants on the site shows each row, a program with no grant too, and the page of each program shows its grants and its other terms.

The build of the system stops when a program has no row, so a new program never starts with a role that nobody wrote. Each program that the root service starts gets each handle and each value of its context through one check, and a start that would write one place twice does not run.
