The window of the debugger now does each act of the debugger without the console.

A developer types a place in one field: a procedure, a file and a line, an address or a global. Three buttons put a breakpoint there, a watch on its bytes, or show 128 bytes of the memory of the program from it. The memory card shows each row as an address, 16 bytes and their characters, and the window reads it again each half second.

A click on a row does what a key does: it chooses a thread or a frame, puts a breakpoint at a source line, or removes a breakpoint.
