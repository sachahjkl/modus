The documentation of a module links terms of the glossary and headings of the guides. The program `manual` now opens them. The boot image carries the page of each term and each heading that a module links, with the headings under it. Tab moves the focus from link to link, and Enter opens the link with the focus. Backspace goes back to the page before, at the row where it was. A link to another host shows its address and does not open: the system has no browser. The picture shows the page of the module `manual` with the focus on the link "the description tables". The machine test opens that link with a press, opens the link of a term with Tab and Enter, and goes back each time.
